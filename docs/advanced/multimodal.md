# 多模态提示（Multimodal Prompting）

你往 ChatGPT 里丢一张图，再问「这页 PPT 配色丑在哪」——它居然真能说出一二三。

这种「图 + 文字」一起丢给模型、让模型把图像也当输入来理解的玩法，就叫**多模态提示（Multimodal Prompting）**。它打破了「提示只能是文字」的刻板印象。

::: tip 一句话定义
**多模态提示（Multimodal Prompting）** = 把文本、图像、音频等多种形式的输入一起交给大语言模型（LLM），让它综合理解并回答，而不只是处理纯文字。
:::

## 为什么多模态值得专门学

纯文字提示有个硬伤：**世界上的很多信息本来就不是文字**。

> 类比：你让同事「帮我看下这个报错」，顺手截图甩过去，比用一段文字描述「红色窗口、左边有个堆栈、第二行写着……」高效十倍。模型也一样。

多模态提示一次解决三类文字搞不定的事：

| 场景 | 纯文字提示的尴尬 | 多模态怎么解 |
| --- | --- | --- |
| 看图 | 「描述一下这张图」你根本没图可传 | 直接传图，让模型看 |
| 对比 | 你很难用文字还原两张图差异 | 两张图一起传，让它对比 |
| 现场 | 拍个仪表盘、菜单、白板就能问 | 语音 + 图像，边指边问 |

新模型把这件事门槛拉得很低：GPT-4o（2024）、GPT-4.5（2025）原生支持图文混合理解；国产这边 Qwen-VL、GLM-4V、Kimi 视觉也都能看图。你基本不用任何额外工具，传图就问。

## 怎么做：三种最常见的玩法

**① 图文混合提问（文本 + 图像）**

最基础：传一张图，再配一句自然语言指令。关键是**把「你想要它做什么」说清楚**——是描述、是挑错、还是按图办事。

**② 图像描述 / 分析 / 对比**

- 描述：让模型讲清图里有什么。
- 分析：让它判断「这张 UI 哪里反直觉」「这份财报图趋势如何」。
- 对比：把两张图传进同一条消息，问「左边和右边差在哪」。多图在同一 `messages` 里是支持的。

**③ 语音输入**

语音本身通常先转成文本再进模型（ASR 那一步）。但 GPT-4o 这类「原生多模态」模型能直接消费音频流，你说话它边听边答，不用你先手动转写。写提示时思路不变：**先把你要问的事想清楚，再决定用说还是用打字。**

## 可复制示例（OpenAI 格式，图文混合）

```js
// 需 API Key：https://platform.openai.com 获取，设为环境变量 OPENAI_API_KEY
// 模型：gpt-4o（OpenAI, 2024 年发布，原生支持图文混合理解）；可换 gpt-4.5（2025）
// 以下为「传一张图 + 问问题」的调用示意，image_url 用本地/网络图片地址
import OpenAI from 'openai'

const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY })

const completion = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    {
      role: 'user',
      // 一条消息里 content 是数组：文本段 + 图像段（type: image_url）
      content: [
        {
          type: 'text',
          text: '这张产品海报有什么明显的设计问题？请挑出 3 个，并给出修改建议。',
        },
        {
          type: 'image_url',
          // 示意：换成你自己的图片 URL 或 base64（data:image/jpeg;base64,...）
          image_url: { url: 'https://example.com/poster.jpg' },
        },
      ],
    },
  ],
})

console.log(completion.choices[0].message.content)
// 输出示例：
// 1) 主标题与背景对比度不足，远处看不清 → 换成深色描边或加深底色；
// 2) 信息层级混乱，卖点和标语权重一样 → 放大卖点、弱化标语；
// 3) 二维码太小且无引导文案 → 放大并加「扫码领券」。
```

> 想对比两张图？在 `content` 数组里再加一个 `image_url` 段即可，然后问题改成「对比这两张图」。

::: warning 常见坑
- **传了图却不说要干啥**：图给了，指令只写「说说看」——模型容易泛泛而谈。请明确「描述 / 分析 / 对比 / 提取文字」哪一种。
- **图片分辨率/体积太高**：很大或很糊的图既费钱又看不清。先用工具压缩或裁剪到关键信息区域，效果往往更好。
- **以为模型「看见」就等于「读懂」**：它能描述图，但不一定理解图里行业术语的真实含义。专业领域（医疗、工程图）结论要你复核。
- **忽略模型支持范围**：不是所有模型都能看图。用前确认该模型支持图像输入（GPT-4o / Qwen-VL / GLM-4V 等），文本模型传图会直接报错。
:::

## 记忆卡片 🃏

> **多模态提示** = 把图、文、音一起喂给模型，让它综合理解。
> 一句话：世界不是纯文字，模型也不必只看文字。
> 关键：传了图，也要说清「你想让它对图做什么」。

## 小结

多模态提示把模型从「只读文字」解放出来，图文混合提问、图像分析对比、语音输入都是当下最实用的姿势。主流模型（GPT-4o / GPT-4.5、Qwen-VL、GLM-4V、Kimi 视觉）已原生支持看图，你基本零成本上手。写了提示想让模型吐出**规整、能直接被程序解析的结果**？下一篇看：[结构化输出（JSON / Function Calling）](/advanced/structured-output)。
